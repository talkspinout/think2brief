핵심 요약

Chrome 확장 프로그램은 개발자 계정·서버, 분석 도구, 광고 추적을 사용하지 않습니다. 사용자가 선택한 경우에만 Google 계정 인증과 Google Drive 저장·열기 기능을 사용합니다. 프로젝트 데이터는 개발자에게 전송되지 않습니다. 제품 소개 웹사이트의 방문 통계와 Drive 파일 선택 전용 페이지는 서로 다르게 운영됩니다 — 자세한 내용은 4번과 8번 항목을 확인하세요.

01

적용 범위와 운영자

이 개인정보 처리방침은 Hongseok Ko(talkspinout)가 제공하는 Chrome 확장 프로그램 Think2Brief — Marketing에 적용됩니다. 제품 소개 웹사이트의 문의는 think2brief@gmail.com에서 받습니다.

02

확장 프로그램이 처리하는 정보

확장 프로그램은 사용자가 직접 입력하거나 생성한 다음 정보를 기능 제공을 위해 브라우저 안에서 처리합니다.

  • 프로젝트 제목과 작성자 표시명
  • 캠페인 목표와 타깃
  • 판단, 근거, 통찰, 전략, 활동, 측정 카드의 내용
  • 카드 상태, 브리프 포함 여부, 연결 메모 및 작성 중인 초안
  • 프로젝트 식별자, 생성·수정 시각 및 데이터 스키마 버전

작성자 표시명과 자유 입력 내용에는 사용자의 선택에 따라 개인정보 또는 업무 정보가 포함될 수 있습니다. 민감하거나 불필요한 개인정보를 입력하지 않는 것을 권장합니다.

03

처리 목적과 저장 위치

위 정보는 다음 기능을 제공하는 데에만 사용됩니다.

  • 작업 중인 프로젝트의 자동 저장과 복구
  • 작업 보드, 전략 정리, 연결 점검 및 최종 브리프 생성
  • 사용자가 요청한 JSON, Markdown 또는 인쇄·PDF 내보내기

자동 저장 데이터는 Chrome 확장 프로그램 전용 localStorage에 저장됩니다. 내보낸 파일은 사용자가 선택한 기기의 위치에 저장되며 이후 관리 책임은 사용자에게 있습니다.

04

수집, 외부 전송 및 제3자 제공

개발자 서버 수집없음
외부 서비스 전송사용자 선택 시 Google Drive
분석·광고 추적없음
개발자 회원 계정없음

이 표는 Chrome 확장 프로그램 기준입니다. 사용자가 Google Drive 저장 또는 열기를 선택하면 Google OAuth 인증 토큰과 선택한 프로젝트 파일이 Google에 전송됩니다. 권한 범위는 이 앱으로 만들거나 사용자가 명시적으로 선택한 파일로 제한됩니다. Notion, LLM API 또는 개발자 서버에는 데이터를 전송하지 않으며, 개발자는 프로젝트를 수집·열람·판매하지 않습니다. 제품 웹사이트의 분석 도구 사용은 8번 항목을 확인하세요.

05

Chrome 권한 사용

확장 프로그램은 Google 계정 인증을 위해 Chrome의 identity 권한과 Google Drive의 drive.file 범위를 사용합니다. 이 권한은 사용자가 Drive 기능을 실행할 때 요청되며, 전체 Drive나 다른 앱이 만든 파일을 임의로 읽을 수 없습니다. 웹사이트 방문 기록이나 다른 탭의 내용에는 접근하지 않습니다.

06

보관과 삭제

자동 저장 데이터는 사용자가 확장 프로그램 안에서 저장 데이터 지우기를 실행하거나 Chrome의 확장 프로그램 데이터를 삭제할 때까지 해당 브라우저에 남습니다.

사용자가 별도로 저장한 JSON, Markdown 또는 PDF 파일은 확장 프로그램의 저장 데이터 지우기 기능으로 삭제되지 않습니다. Google Drive에 저장한 파일도 연결 해제 시 삭제되지 않으며, 해당 파일은 사용자가 직접 삭제해야 합니다.

07

보안과 사용자의 선택

Google Drive 기능을 선택한 경우에만 프로젝트 파일이 암호화된 HTTPS 연결을 통해 Google로 전송됩니다. OAuth 인증 토큰은 URL, 웹 저장소 또는 개발자 서버에 저장하지 않고 파일 선택 과정의 브라우저 메모리에서만 일시적으로 처리합니다. 사용자는 기기 계정, Chrome 프로필, Google 계정 및 내보낸 파일의 접근 권한을 안전하게 관리해야 합니다.

08

제품 웹사이트

제품 소개 및 이 처리방침 페이지는 GitHub Pages에서 호스팅됩니다. 웹사이트 방문 과정에서 GitHub가 접속 기록 등 기술 정보를 처리할 수 있으며, 이는 GitHub 개인정보 보호정책 의 적용을 받습니다.

이 웹사이트는 방문 통계를 확인하고 사이트를 개선하기 위해 Google 태그 관리자를 통해 Google 애널리틱스 4를 사용합니다. 이 과정에서 방문 페이지, 기능 이용 이벤트, 기기·브라우저 정보, IP 주소에서 산출된 대략적인 지역, 쿠키 또는 유사 식별자가 처리될 수 있습니다. 사용자가 확장 프로그램에 작성한 프로젝트·카드·브리프 내용은 웹사이트 분석 정보에 포함되지 않습니다. 수집된 정보는 Google로 전송되어 Google 개인정보 보호정책의 적용을 받습니다. 브라우저의 쿠키 설정 또는 Google 애널리틱스 차단 확장 프로그램을 통해 수집을 제한할 수 있습니다. 최초 방문 시 표시되는 동의 화면에서 분석을 거부할 수 있으며, 페이지 하단의 ‘분석 설정’에서 언제든 선택을 변경할 수 있습니다. 동의 전에는 Google 태그 관리자와 Google 애널리틱스를 불러오지 않습니다.

Chrome 확장 프로그램 자체는 이 웹사이트와 별개로 동작하며, 태그 관리자를 포함하지 않고 어떤 분석 도구도 사용하지 않습니다. Drive 파일 선택 전용 페이지 /drive-picker/에도 태그 관리자와 분석 도구를 설치하지 않습니다. 확장 프로그램은 이 페이지 URL에 OAuth 토큰, 프로젝트 내용 또는 고유 프로젝트 식별자를 포함하지 않습니다. 일회용 연결값과 확장 프로그램 출처만 전달하며, 인증 토큰은 출처·창·일회용 연결값을 확인한 뒤 브라우저 메시지로 전달됩니다.

09

향후 기능과 정책 변경

개인정보 처리 방식이 변경되는 경우, 변경된 수집 항목과 이용 목적을 개인정보 처리방침 및 확장 프로그램 화면을 통해 사전에 안내합니다. 새로운 데이터 수집·이용이 시작되는 경우 사용자가 명시적으로 동의하기 전에는 해당 데이터를 처리하지 않습니다. 또한 변경 사항을 배포하기 전에 Chrome 웹스토어의 개인정보 공개 내용을 최신 상태로 갱신합니다.

중요 변경 사항은 시행일과 정책 버전을 이 페이지에 표시합니다.
